# fmristore Test Fixtures for fmrigds

## Overview

This document describes the synthetic test fixtures created for testing the fmristore adapter integration in fmrigds.

## Location

```
tests/testthat/testdata/
  ├── labeled_volume_small.h5       # LabeledVolumeSet fixture (~29 KB)
  ├── parcellated_small.h5          # H5ParcellatedMultiScan fixture (~121 KB)
  └── latent_vec_small.lv.h5        # LatentNeuroVec fixture (pending)
```

## Generation

Fixtures are generated using:
```r
source("tests/testthat/helpers-generate-test-fixtures.R")
generate_all_fmristore_fixtures()
```

Fixtures are automatically created when tests run if they don't exist.

## Fixture Details

### 1. LabeledVolumeSet (`labeled_volume_small.h5`)

**Layout Type:** `labeled_volume`
**Dimensions:** 4×5×3 spatial, 2 contrasts
**Mask Coverage:** 60% of voxels (36/60 total)
**File Size:** ~29 KB

**HDF5 Structure:**
```
/header/              # NIfTI-like metadata
  dim: [4, 4, 5, 3, 2, 1, 1, 1]
  pixdim: [0.0, 2.0, 2.0, 2.0, ...]
  quatern_b, quatern_c, quatern_d
  qoffset_x, qoffset_y, qoffset_z
  qfac
  srow_x, srow_y, srow_z
/mask                 # 3D [4,5,3] binary mask
/labels               # ["contrast_A", "contrast_B"]
/data/
  contrast_A          # 1D [36] packed voxels
  contrast_B          # 1D [36] packed voxels
```

**GDS Mapping:**
- **Space:** `space_voxel(dim = c(4,5,3), storage = "packed")`
- **Dimensions:** `[sample=36, subject=1, contrast=2]`
- **Assays:** `beta` (data from `/data/<label>`)
- **Contrasts:** `c("contrast_A", "contrast_B")`

**Generated by:** `generate_labeled_volume_fixture()`

### 2. H5ParcellatedMultiScan (`parcellated_small.h5`)

**Layout Type:** `parcellated`
**Dimensions:** 4×5×3 spatial, 3 clusters/parcels, 2 runs
**Run 1:** 10 timepoints (full voxel data)
**Run 2:** 12 timepoints (summary data)
**File Size:** ~121 KB

**HDF5 Structure:**
```
/header/              # NIfTI-like metadata
/mask                 # 3D binary mask (master)
/space/               # NeuroSpace serialization
/cluster_map          # 3D integer [4,5,3] with cluster IDs
/cluster_ids          # [1, 2, 3]
/cluster_names        # ["MasterCluster_1", ...]
/scans/
  Run1_Full/          # Full voxel-level data
    mask
    cluster_map
    cluster_ids
    cluster_names
    clusters/
      cluster_1       # [10 timepoints × n_voxels_in_cluster_1]
      cluster_2
      cluster_3
  Run2_Summary/       # Summary (mean per cluster)
    mask
    cluster_map
    cluster_ids
    cluster_names
    clusters_summary/
      summary_data    # [12 timepoints × 3 clusters]
```

**GDS Mapping:**
- **Space:** `space_parcels(labels = c("1", "2", "3"))`
- **Dimensions:** `[sample=3, subject=2, contrast=1]` (after temporal aggregation)
- **LinearMap:** Voxel → Parcel averaging operator
- **Challenge:** Temporal dimension needs aggregation strategy

**Generated by:** `generate_parcellated_fixture()`

**Generated by:** `generate_latent_vec_fixture()` (pending neuroim2 fix)

## Known Issues

1. **LatentNeuroVec fixture not generated**: `neuroim2::LatentNeuroVec` not exported in current neuroim2 version
2. **Parcellated temporal aggregation**: Need to define strategy for converting `[clusters × time]` → `[sample × subject × contrast]`
3. **Label sanitization**: Adapter must sanitize labels (replace non-alphanumeric with `_`) to match fmristore write behavior

## Regenerating Fixtures

To regenerate all fixtures (e.g., after changing dimensions or seed):

```r
# From package root
source("tests/testthat/helpers-generate-test-fixtures.R")

# Regenerate all
generate_all_fmristore_fixtures()

# Or regenerate individually
generate_labeled_volume_fixture(
  output_path = "tests/testthat/testdata/labeled_volume_small.h5",
  dims = c(4, 5, 3),
  n_contrasts = 2
)
```
